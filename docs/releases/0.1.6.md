# Flit 0.1.6

首个打包发布版本：用 ⌘Tab 切换 macOS 桌面与全屏窗口，并将最近切换的目标自动移到首位。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `Flit-0.1.6-macos-arm64.dmg` | 推荐安装方式，打开后将 Flit 拖入 Applications。 |
| `Flit-0.1.6-macos-arm64.zip` | 压缩包，解压后将 Flit.app 放入“应用程序”。 |
| `SHA256SUMS.txt` | 两个安装包的 SHA-256 校验值。 |

下载地址：[GitHub Release v0.1.6](https://github.com/msunx/flit/releases/tag/v0.1.6)。

**架构：Apple Silicon（arm64），不包含 Intel 版本。** 系统部署目标为 macOS 14+；实际验收环境为 Apple Silicon / macOS 27.0.1，其他系统版本尚未逐一验证。

安装前退出正在运行的 Flit。安装到固定位置后再打开，在「权限与启动」中开启辅助功能；屏幕录制为可选，用于预览，未开启也可按名称切换。升级可能需要重新添加辅助功能或屏幕录制授权，原有设置文件会保留。

**当前包使用临时签名，未经 Developer ID 签名或 Apple 公证。** 如果 macOS 阻止首次打开，请确认下载来源后，在系统设置的「隐私与安全性」中按提示确认打开；具体步骤参见 [Apple 支持](https://support.apple.com/102445)。

## 包含的功能

- 桌面空间与全屏窗口各占一项，桌面中的普通应用窗口不单独列出。
- 默认 ⌘Tab，支持自定义快捷键；按住选择、松开切换，Shift 反向，Esc 取消。
- 通过 Flit 成功切换后自动置顶，可在最近两个目标间往返；排序保留在本次运行会话。
- 鸢尾浅色界面，支持预览网格、紧凑列表、搜索与自定义名称。
- 直接到达目标空间，无需唤出 Mission Control 或播放逐项横向切换动画。
- 可选将底部 Dock 固定到指定显示器，防止鼠标在其他屏幕底部停留时将它唤走。

## 兼容说明

空间切换使用部分非公开 macOS 接口，系统升级可能影响兼容性。空桌面导航要求鼠标位于目标屏幕，多显示器场景尚未完整验收。Dock 固定适用于多屏、底部 Dock 及「显示器具有单独的空间」模式。

预览只在内存缓存，不上传、不写入磁盘。桌面使用最近访问时的画面；尚未访问、受保护或不可捕获的内容显示占位或图标。

## 校验下载

在下载目录运行以下命令，将结果与 `SHA256SUMS.txt` 中同名文件对应的值比较：

```sh
shasum -a 256 Flit-0.1.6-macos-arm64.dmg
```
